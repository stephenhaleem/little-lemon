
# Little Lemon Restaurant - Table Booking App

## Project Overview

Little Lemon is a responsive restaurant table booking application built with React.

This project was developed as part of the Meta Front-End Developer Capstone on Coursera.

## Features

- Responsive restaurant homepage
- Table reservation form
- Date and time selection
- Number of guests selection
- Customer contact information
- Form validation and error messages
- Reservation confirmation screen
- Accessible form labels and semantic HTML
- Unit tests using Vitest and React Testing Library

## Technologies Used

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Vitest
- React Testing Library

## Installation

1. Clone the repository:

   git clone YOUR_REPOSITORY_URL

2. Navigate to the project folder:

   cd little-lemon

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed in your terminal.

## Running Tests

Run the following command:

   npm test

## Production Build

To create a production build:

   npm run build

## How to Book a Table

1. Open the Little Lemon website.
2. Click "Reserve a Table".
3. Select a date and time.
4. Choose the number of guests.
5. Enter your name, email, and phone number.
6. Click "Confirm Reservation".
7. View your reservation confirmation.

## Limitations

This is a frontend demonstration project.

Reservations are stored only in React component state and are not saved to a database.

Time slots are predefined and do not represent real-time restaurant availability.
